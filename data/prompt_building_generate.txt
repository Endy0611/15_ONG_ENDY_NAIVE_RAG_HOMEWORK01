Prompt Building and Grounded Generation in RAG

Once the retriever returns the top matching chunks for a question, the next job is turning those chunks and the question into a single prompt that gets sent to the language model. This step is often called prompt augmentation, because the original question is "augmented" with retrieved context before it ever reaches the model.

A simple augmented prompt usually has three parts: a system instruction, a context block, and the question itself. The system instruction tells the model how to behave, for example instructing it to answer only using the provided context and to say so plainly if the answer is not contained in that context. The context block lists the retrieved chunks, often numbered and labeled with their source filename so the model (and anyone reading the logs) can see exactly what evidence it was given. The question is placed last, right before asking the model to answer.

Grounded generation means the final answer should be traceable back to the retrieved chunks rather than coming from the model's own memorized knowledge. This is why the system instruction explicitly restricts the model to the given context, and why many RAG systems ask the model to cite which source chunk it used for each part of its answer. Grounding is what makes a RAG answer trustworthy: if a claim in the answer cannot be found in the context block, it is a sign the model ignored the instruction and hallucinated instead of retrieving.

One common failure mode is when retrieval returns weak or irrelevant chunks, for example because the question is about something the documents never cover. Without a safeguard, the model may still try to produce a confident-sounding answer using only general knowledge. A simple fix is to check the similarity score of the retrieved chunks before even calling the model: if the closest chunk is still far from the question in embedding space, the system can skip generation entirely and tell the user it could not find the answer in the documents, rather than risking a hallucinated response.
